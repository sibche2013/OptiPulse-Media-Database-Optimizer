== Description ==

Smart Media & Database Optimizer is a lightweight, all-in-one performance toolkit engineered to speed up your website by optimizing media assets and cleaning database overhead without third-party dependencies.

**Key Features:**

* **Next-Gen Image Conversion:** Automatically converts uploaded JPEG/PNG images to modern WebP or AVIF formats on upload to cut asset weight by up to 60%.
* **Granular Quality Slider:** Configure compression ratios (0-100%) for converted assets with Imagick/GD fallback support.
* **Media Size Control (ISQM):** Disable redundant thumbnail crops generated by themes and core to prevent server disk bloat.
* **Safe Asset Fallback:** Prevent 404 broken image errors by automatically routing missing thumbnail requests to master files.
* **Database Janitor:** Single-click cleanup of post revisions, auto-drafts, orphaned postmeta, spam/trashed comments, and broken taxonomy relations.
* **Expired Transients Cleaner:** Purge timed-out transients and orphaned timeout entries to keep `wp_options` small.
* **InnoDB Table Defragmentation:** Optimize core tables (`posts`, `postmeta`, `options`, `comments`, etc.) to reclaim disk overhead and rebuild indexes.
* **WooCommerce Action Scheduler Maintenance:** Prune complete, failed, and canceled action queues and configure custom log retention periods (e.g., 2 to 30 days) via AJAX.
* **Autoload Footprint Analyzer:** Real-time diagnostics for `wp_options` total autoload size and a breakdown of the top 10 heaviest rows.
* **Responsive Fancybox Slider:** Automatically upgrades standard WordPress and Elementor galleries into mobile-ready lightboxes.
* **Pure Vanilla AJAX UI:** Perform configuration saves and database purges asynchronously with custom confirmation modals and zero full-page refreshes.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/smart-media-database-optimizer/` directory or install directly via the WordPress Plugins dashboard.
2. Activate the plugin.
3. Access the panel via the top-level dashboard menu: **Smart Optimizer** (بهینه‌ساز هوشمند).

== Frequently Asked Questions ==

= Is a database backup mandatory before using cleanup tools? =
Yes. Database purges execute direct `DELETE` and `OPTIMIZE` operations. Always create a full SQL dump or host-level backup before proceeding.

= Does WebP or AVIF conversion affect existing media? =
No. The conversion filter hook targets newly uploaded media files during ingestion.

= Which image engine is required? =
The plugin supports both PHP GD and Imagick, dynamically testing whether your hosting environment provides WebP and AVIF MIME capabilities.
