🚀 OptiPulse: Media & Database Optimizer

All-in-one performance toolkit: WebP/AVIF converter, database cleaner, and Fancybox lightbox

⚡ Live Demo ✨ WebP & AVIF Ready 🗄️ MySQL & WooCommerce Cleaner WordPress 5.0 - 7.x

افزونه OptiPulse: Media & Database Optimizer یک راهکار جامع، ایمن و سبک برای ارتقای اساسی راندمان وردپرس است که دو عامل کلیدی افت سرعت سایت یعنی حجم سنگین تصاویر و انباشت داده‌های زائد در MySQL را با مکانیزم‌های مدرن و غیرهمگام مدیریت می‌کند.

✨ امکانات اصلی افزونه

⚡
تبدیل خودکار به WebP و AVIF تبدیل درلحظه تصاویر آپلودی به فرمت‌های نسل جدید وب جهت کاهش حجم تا ۶۰٪ و بهبود محسوس امتیاز Core Web Vitals.
🎛️
کنترل دقیق کیفیت فشرده‌سازی امکان تنظیم درصد کیفیت فایل‌های خروجی همراه با قابلیت قفل کیفیت JPEG و PNG روی ۱۰۰٪ برای جلوگیری از افت جزئیات در برش‌ها.
✂️
مهار برش‌های اضافه (ISQM) انتخاب و مسدودسازی سایزهای پیش‌فرض و غیرضروری قالب‌ها جهت جلوگیری از اشغال بی‌رویه هارد دیسک سرور.
🗄️
پاک‌سازی جامع دیتابیس (MySQL Janitor) حذف ایمن رونوشت‌ها (Revisions)، پیش‌نویس‌های خودکار، متادیتای یتیم پست‌ها، دیدگاه‌های اسپم/زباله‌دان و ترم‌های نامعتبر با AJAX.
⏱️
حذف ترنزینت‌های منقضی تخلیه رکوردهای کش تاریخ‌گذشته و زباله‌های جا مانده در جدول wp_options برای تسریع زمان پاسخگویی پایگاه داده.
🛠️
دیفرگمنت و یکپارچه‌سازی جداول (OPTIMIZE) آزادسازی فضای خالی و سربار (Overhead) دیسک موتور InnoDB و نوسازی ایندکس‌های ۸ جدول کلیدی وردپرس.
🛒
مدیریت لاگ‌های Action Scheduler ووکامرس پاک‌سازی اکشن‌های تاریخ‌گذشته و امکان سفارشی‌سازی دوره نگهداری لاگ‌ها (مثلاً ۲ یا ۵ روز به جای ۳۰ روز پیش‌فرض).
📊
تحلیلگر زنده بارگذاری Autoload محاسبه لحظه‌ای حجم داده‌های Autoload در جدول گزینه‌ها و نمایش ۱۰ رکورد حجیم برای رفع کندی‌های مرموز سایت.
🖼️
گالری لایت‌باکس Fancybox تبدیل خودکار گالری‌های وردپرس و المنتور به اسلایدر ریسپانسیو و لمسی با دکمه‌های زوم، بندانگشتی و تمام‌صفحه.
🛡️
جایگزینی هوشمند تصویر (Fallback) جلوگیری از نمایش تصویر شکسته و خطای ۴۰۴ با روت خودکار درخواست‌های سایز گمشده به تصویر اصلی.

🛠️ راهنمای راه‌اندازی سریع

۱. پوشه افزونه را با نام optipulse-media-database-optimizer در دایرکتوری wp-content/plugins/ آپلود کنید.

۲. افزونه را از بخش «افزونه‌ها» در پیشخوان وردپرس فعال کنید.

۳. برای پیکربندی و پاک‌سازی، به منوی جدید بهینه‌ساز هوشمند در نوار اصلی پیشخوان مراجعه فرمایید.

OptiPulse: Media & Database Optimizer is an all-in-one, zero-dependency WordPress optimization solution that addresses the two biggest performance bottlenecks: oversized media and bloated database tables.

✨ Core Features

⚡
Auto WebP & AVIF Conversion Converts image uploads to next-gen formats on the fly, cutting file weight by up to 60% and boosting Core Web Vitals.
🎛️
Granular Compression Control Customize output compression quality with GD and Imagick support, plus lossless 100% ratios for native uploads.
✂️
Thumbnail Crop Janitor (ISQM) Disable unwanted intermediate crop sizes generated by themes and core to prevent server disk bloat.
🗄️
Full MySQL Janitor & Cleanup Purge post revisions, auto-drafts, orphaned postmeta, spam comments, and broken taxonomy relations via asynchronous AJAX.
⏱️
Expired Transients Cleaner Purge timed-out transients and orphaned timeout entries to keep wp_options lightweight and fast.
🛠️
InnoDB Table Defragmentation Reclaim disk overhead and rebuild indexes across 8 critical WordPress tables with single-click table optimization.
🛒
WooCommerce Action Scheduler Pruning Clear complete, failed, and canceled actions and configure custom log retention windows (e.g., 2 to 30 days).
📊
Real-time Autoload Diagnostics Live footprint calculation of wp_options autoload size with a breakdown of the top 10 heaviest entries.
🖼️
Fancybox Lightbox Integration Automatically wraps standard WordPress and Elementor galleries into touch-friendly, responsive modal sliders.
🛡️
Safe Asset Fallback Pipeline Prevents 404 broken image containers by routing requests for missing intermediate crops directly to master files.

🛠️ Quick Setup

1. Upload the plugin folder to your wp-content/plugins/optipulse-media-database-optimizer/ directory.

2. Activate the plugin via the 'Plugins' menu in your WordPress dashboard.

3. Access settings via the new top-level admin menu: Smart Optimizer (بهینه‌ساز هوشمند).
