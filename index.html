🚀 Smart Media Manager

The ultimate toolkit to optimize, convert, and enhance your WordPress media library

⚡ Live Demo ✨ WebP & AVIF Ready WordPress 5.0+ PHP 7.4 - 8.x

افزونه Smart Media Manager یک ابزار پیشرفته، ایمن و بسیار سبک است که تمام نیازهای شما برای مدیریت تصاویر سایت (از فشرده‌سازی تا رابط کاربری گالری‌ها) را در یک پنل ساده برطرف می‌کند.

✨ قابلیت‌های اصلی افزونه

⚡
تبدیل خودکار به WebP و AVIF تصاویر آپلودی شما در لحظه به فرمت‌های فوق‌فشرده و مدرن وب تبدیل می‌شوند تا سرعت سایت و سئو به شدت افزایش یابد.
🎛️
کنترل دقیق فشرده‌سازی (Quality) امکان تنظیم درصد کیفیت فرمت‌های جدید (مثلاً ۸۰٪) برای کاهش حجم، در کنار قفل کردن کیفیت عکس‌های اورجینال روی ۱۰۰٪.
✂️
مهار سایزهای اضافی (ISQM) جلوگیری از ساخته شدن ابعاد بلااستفاده توسط وردپرس یا قالب‌ها که موجب صرفه‌جویی عظیم در فضای هارد هاست شما می‌شود.
🖼️
گالری لایت‌باکس (Fancybox) تبدیل خودکار گالری‌های ساده وردپرس و المنتور به اسلایدرهای لمسی، مدرن و ریسپانسیو با استفاده از کتابخانه قدرتمند Fancybox.
🛡️
جایگزینی تصویر اصلی (Fallback) سیستم هوشمند برای جلوگیری از خطای ۴۰۴ تصاویر شکسته در سایت. اگر سایز کوچکی پاک شده باشد، تصویر اصلی نمایش داده می‌شود.
🧠
بررسی هوشمند سرور و ویرایشگر آنالیز زنده اکستنشن Imagick هاست شما برای جلوگیری از خطا، به همراه قابلیت غیرفعال‌سازی سریع ویرایشگر گوتنبرگ.

🛠️ نحوه نصب و استفاده

۱. پوشه افزونه را در مسیر wp-content/plugins/ آپلود کنید.

۲. افزونه را از بخش «افزونه‌ها» در پیشخوان وردپرس فعال کنید.

۳. برای اعمال تنظیمات، به منوی جدید رسانه ← Smart Media Manager مراجعه کنید.

Smart Media Manager is an advanced, lightweight utility plugin designed for the WordPress Media Library, granting you full control over storage parameters, next-gen image conversion, and front-end gallery presentations.

✨ Core Plugin Features

⚡
Auto WebP & AVIF Conversion Instantly convert uploaded images to ultra-compressed next-gen formats to drastically boost page speed and core web vitals.
🎛️
Precision Quality Control Adjust the compression percentage for next-gen formats while keeping original JPG/PNG uploads at 100% lossless quality.
✂️
Thumbnail Layout Control (ISQM) List and disable intermediate image sizes generated by active themes or plugins, heavily decreasing host disk space usage.
🖼️
Fancybox Lightbox Integration Automatically detects basic WordPress or Elementor image galleries and wraps them into premium touch-responsive Fancybox sliders.
🛡️
Smart Image Fallback Pipeline Intercepts broken front-end images (404 errors) and substitutes missing target sizes with the master original image source automatically.
🧠
Server Diagnostics & Classic Editor Automatically detects Imagick extension compatibility for safe conversions, plus a one-click toggle to disable Gutenberg block editor.

🛠️ Installation Steps

1. Upload the plugin directory to your wp-content/plugins/ folder.

2. Activate the plugin via the 'Plugins' menu in your WordPress dashboard.

3. Navigate to the dashboard link: Media ← Smart Media Manager to configure options.
